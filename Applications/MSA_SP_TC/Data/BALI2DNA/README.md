# BALI2DNA reference alignments

This folder contains the six reference alignments used in the MSA
experiments. The files are distributed with the BALI2DNA benchmark
associated with BAliBASE. Their matching unaligned nucleotide input files
are in `../Input/`.

Reference files are used only for post-optimization SP/TC evaluation.
They are not used to construct the UPGMA guide tree, initialize the
Profile-HMM, optimize its parameters, or perform Viterbi decoding.

Original benchmark source:
https://www.drive5.com/bench/bench.tar.gz
