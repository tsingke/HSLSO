# UAV Path-Planning Supplementary Code

This package contains the MATLAB implementation used for the UAV path-planning comparison experiment.

## Included algorithms

- HSLSO
- SCLDPSO
- EAPSO
- SLPSO
- CSO

## Main file

Run `run_UAV_comparison.m` in MATLAB. The script generates the synthetic 3-D terrain, runs the five algorithms under the same population size and iteration budget, plots the paths and convergence curves, and reports the UAV path metrics.

## Experiment settings

The settings in `run_UAV_comparison.m` are retained from the experiment code, including the random seed, start and goal positions, population size, number of waypoints, iteration budget, and UAV path constraints.

## Terrain data

No external terrain dataset is required for this experiment. The terrain is generated by `Terrain/defMap4.m`; the fixed random seed in the main script makes the generated terrain reproducible.

## Folder structure

- `Algorithms/`: optimization algorithms used in the comparison
- `Core/`: path decoding, fitness evaluation, and quantitative metrics
- `Terrain/`: synthetic terrain generation
- `Utilities/`: plotting and result-printing routines
